\subsection*{Overview}

The FRFP Lean library is structured in five dependency layers. No module imports
a module from a higher layer. The dependency graph is acyclic; the build system
(Lake) verifies this property.

\subsection*{Minimal Module Dependency Map}

The three minimal modules compile independently of the full core:

\begin{center}
\begin{tabular}{ll}
\toprule
Module & Imports \\
\midrule
\texttt{Frfp/Minimal/MinimalCore.lean} & \texttt{Mathlib.Tactic} only \\
\texttt{Frfp/Minimal/MinimalBasis.lean} & \texttt{MinimalCore} \\
\texttt{Frfp/Minimal/MinimalReport.lean} & \texttt{MinimalBasis} \\
\bottomrule
\end{tabular}
\end{center}

This independence is intentional. The minimal basis can be used as a lightweight
dependency for projects that only need the 7-primitive FRFP foundation.
