\section{Formal System Architecture}

The FRFP Lean library is structured in five dependency layers with an acyclic
import graph enforced by Lake. No module imports from a higher layer.

\subsection{Design Constraints}

\begin{enumerate}
  \item Immutable kernel definitions after stabilization.
  \item Explicitly typed interfaces across semantic, probabilistic, and governance layers.
  \item Citation discipline for all retained axioms.
\end{enumerate}
